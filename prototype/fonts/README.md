Shanhai WenKai Prototype is a renamed character subset of LXGW WenKai Lite Regular. Source: https://github.com/lxgw/LxgwWenKai-Lite . Distributed under SIL Open Font License 1.1, included in WenKai-OFL.txt. Copyright retained in license and font metadata. This subset extends the original Boyi website typography to the prototype content. Regenerate from the licensed full font when adding characters. Decorative symbols not supported by the source font use system fallback.
